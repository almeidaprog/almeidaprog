### 🚀 Projetos em destaque

#### 🛡️ [SIARC — Sistema Inteligente de Auditoria e Resiliência Cibernética](https://github.com/almeidaprog/siarc-platform)

Projeto acadêmico de pesquisa e desenvolvimento voltado ao processamento de eventos de segurança, auditoria e análise de riscos cibernéticos.

A plataforma utiliza uma API desenvolvida em FastAPI, persistência em PostgreSQL, serviços containerizados com Docker e automação de fluxos com n8n.

Também foi desenvolvido um dashboard para acompanhar o funcionamento dos serviços, métricas operacionais, registros de auditoria e classificações de risco.

**Resultados da validação experimental:**
- 43.369 requisições em testes de carga, sem falhas HTTP registradas.
- 48 cenários de validação do mecanismo de classificação de risco.
- 350 execuções ponta a ponta dos fluxos n8n, sem falhas registradas nos testes.

**Tecnologias:** Python, FastAPI, PostgreSQL, Docker, n8n e Locust.

#### ☕ [API de Fichas de RPG](https://github.com/almeidaprog/projetoJavaREAL)

Projeto back-end desenvolvido com Java e Spring Boot, voltado ao gerenciamento de fichas de personagens de RPG.

A aplicação envolve criação de APIs REST, implementação de regras de negócio, autenticação com JWT e persistência de dados.

O projeto permitiu praticar organização de código, desenvolvimento de endpoints e estruturação de uma aplicação back-end.

**Tecnologias:** Java, Spring Boot, MySQL e JWT.
